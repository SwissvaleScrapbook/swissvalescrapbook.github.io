# Swissvale Scrapbook Website
Code repository for the public facing Swissvale Scrapbook website. Hosted at https://swissvalescrapbook.github.io/

## Tech Stack
- React
- TypeScript
- Vite Build Tool
- TailwindCSS
- ReactRouterDom

## Steps to run website locally:
- Copy the repository to your local machine
- Open a code terminal on your machine or in your favorite IDE
- Navigate to the root directory of the repository
- Type ``` npm run dev ```
- Click the ```localhost``` link that appears in the terminal or navigate to http://localhost:5173/ in your browser
